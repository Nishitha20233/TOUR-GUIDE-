# TOUR-GUIDE-

The objective of this tour guide project is to develop an interactive and informative web-based platform that allows users to explore and learn about notable cities and their famous attractions. Specifically, the project aims to provide an easy-to-use interface where users can select a city such as Hyderabad and access comprehensive information about 15-20 famous places in city. The project seeks to promote tourism by showcasing each city's unique landmarks with engaging descriptions and high-quality photos.
Additionally, it aims to offer detailed information about each attraction, including its location, ticket prices, and available transportation options, to help tourists plan their visits effectively. By serving as an educational resource, the project will allow users to learn about the cultural, historical, and recreational significance of each place. Overall, the goal is to provide a seamless and enjoyable navigation experience, where users can click on places of interest and be directed to detailed pages about each attraction, making the platform a valuable tool for tourists, educators, and anyone interested in exploring these vibrant cities.

Dropdown selection of city ,displays 15–20 popular places per city with images and names.
Clicking on a place opens a new page with:Place description,Location,Ticket pricing (if applicable)
